open_ext4 for Mac — First-Run Guide
===================================

A native ext2/ext3/ext4 driver for macOS, built on FSKit. Reading a Linux
disk works out of the box; writing and the optional pieces take a couple of
one-time steps.


1. Install the app
------------------

Drag Ext4Mac.app onto the Applications folder in this window.


2. Enable the file-system extension
-----------------------------------

macOS ships file-system extensions disabled until you approve them:

  System Settings  →  General  →  Login Items & Extensions
    →  File System Extensions  →  turn on "open_ext4 (ext2/3/4)"

Plug in an ext4 disk (or open a disk image) and it mounts read-only
immediately. That is all most people need.


3. (Optional) Writing to USB sticks — the barrier daemon
--------------------------------------------------------

A journal is a claim about write ordering, and macOS gives a third-party
driver no way to enforce it on removable media. Without an enforced write
barrier, a stick pulled mid-write can come back corrupt — so removable media
mounts read-only until a tiny privileged helper is installed to issue the
barrier. Disk images and internal disks are always read-write and need none
of this.

To enable writing to USB sticks, from a checkout of the project in Terminal:

    make sign
    sudo make install-barrier

Then grant the helper Full Disk Access (it cannot be automated):

  System Settings  →  Privacy & Security  →  Full Disk Access  →  +
    press  ⌘⇧G,  enter  /Library/PrivilegedHelperTools,
    add  ext4barrierd

With that in place, removable media mounts read-write whenever the driver
confirms a real barrier on the device.


4. (Optional) Formatting from Disk Utility
------------------------------------------

    sudo make install-diskutil

adds ext2/ext3/ext4 to Disk Utility's Erase menu and to
`diskutil listFilesystems`.


Notes
-----

- Requires macOS 15.4 or later on Apple Silicon.
- Eject removable media before unplugging it.
- Keep a backup of anything you cannot lose. This is young software.

Project and source:  https://github.com/h3ct0r/open_ext4_for_mac
